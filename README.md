# InfiniteKR's Auktion (Fork)

Fabric-Mod fuer **Minecraft 1.21.11** (Client-seitig).

Live-Auktion fuer Streams: liest `/pay`-Einnahmen aus dem Chat und zeigt
Item, Mindestgebot und Bieterliste in einem Fenster.

## Installation

1. [Fabric Loader](https://fabricmc.net/use/installer/) >= 0.16.0
2. **Fabric API** installieren (wird benoetigt)
3. `InfiniteKR-Auktion-1.21.11.jar` in den `mods`-Ordner legen
